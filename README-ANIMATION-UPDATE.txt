Learning Life Dashboard — animated sticker update

This build replaces the two static Bubu & Dudu stickers in the dashboard header and greeting area with the two user-provided MP4 animations:
- assets/video/header-bears-animation.mp4 (1000064667.mp4)
- assets/video/greeting-bears-animation.mp4 (1000064658.mp4)

Both are configured to autoplay, loop, and remain muted with inline playback on mobile browsers. The dashboard cooking video and other layout content are unchanged.

To publish: extract this ZIP and upload the contents of LearningLife-From-Scratch-v1 to the root of the GitHub Pages repository, replacing the previous prototype files. If the browser shows an older cached version, refresh the page or clear the site cache.
