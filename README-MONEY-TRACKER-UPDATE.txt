Learning Life — Money Tracker update

This update adds the Money Tracker page to the supplied fresh-start project.

Included:
- Overview, Transactions, and Wallets tabs
- Income and expense entry forms
- Cash, GCash, and Maya starter wallets, plus add-wallet option
- Wallet-to-wallet transfers recorded separately (not counted as income or expenses)
- Wallet balances recalculated from saved transactions
- Local browser storage for money records
- Savings summary reads the separate Learning Life savings total if one is present in local storage
- Existing loading screen, welcome/name page, dashboard, animations, videos, stickers, and styling assets retained

To publish:
1. Extract the ZIP.
2. Upload the contents inside Learning-Life--main to the root of your GitHub Pages repository, replacing the matching project files.
3. Keep the assets folders in their same locations.
4. Open the site and use a hard refresh if an older cached copy appears.

Note: This is a browser-local prototype. Money records are stored in the browser's localStorage on that device/browser; they do not sync between devices or browsers.
